## 🚀 Run the Application

### Terminal 1 - Backend
```bash
cd task-portal/backend
mvn spring-boot:run
```

### Terminal 2 - Frontend
```bash
cd task-portal/frontend
npm install
npm run dev
```

### Open Browser
```
http://localhost:5173
```

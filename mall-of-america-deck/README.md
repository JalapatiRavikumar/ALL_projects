# Mall of America - Interactive Sales Deck

An immersive, browser-based sales presentation tool for Mall of America, designed to pitch to prospective retail tenants, corporate sponsors, and event partners.

## Project Overview

This interactive deck transforms the traditional sales pitch into a cinematic, self-guided experience that showcases Mall of America as more than just a shopping destination—it's a world-class entertainment and lifestyle platform.

**Subject Property:** Mall of America (Bloomington, Minnesota)
- 5.6 million square feet
- 40+ million annual visitors
- 520+ stores
- Nickelodeon Universe theme park
- SEA LIFE Minnesota Aquarium
- Multiple event venues and entertainment options

## Tech Stack

- **Frontend Framework:** React 18 with Vite
- **Styling:** Tailwind CSS for responsive design
- **Animations:** Framer Motion for smooth transitions
- **Video:** Native HTML5 with optimized loading
- **Deployment:** Vercel
- **AI Tools Used:**
  - ChatGPT for content strategy and copy refinement
  - Claude for code architecture and component design
  - Midjourney/DALL-E for supplemental imagery where needed

## Setup Instructions

### Prerequisites
- Node.js 18+ and npm/yarn

### Installation

```bash
# Clone the repository
git clone [repository-url]
cd mall-of-america-deck

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Design Decisions

### Visual Direction
- **Luxury minimalism**: Clean layouts with maximum impact
- **Video-centric**: Every section uses video to tell the story
- **Data-driven**: Demographics and metrics presented visually
- **Cinematic pacing**: Scroll-triggered reveals and transitions
- **Premium typography**: Modern, confident, accessible

### User Experience
- **Non-linear navigation**: Sticky nav allows jumping to any section
- **Progressive disclosure**: Information unfolds as user scrolls
- **Clear CTAs**: Every section drives toward business action
- **Dual-use design**: Works both screen-shared and standalone
- **No learning curve**: Intuitive from first second

### Content Strategy
- **First 10 seconds**: Establish scale, energy, differentiation
- **Middle sections**: Build case with data, visuals, storytelling
- **Final sections**: Clear paths to action (lease, sponsor, book)
- **Emotional arc**: Inspire → Inform → Activate
